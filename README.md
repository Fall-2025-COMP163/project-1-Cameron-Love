
# COMP 163 - Project 1: Character Creator & Chronicles

# 🎯 Game Concept

My game is a text-based RPG game where users choose from 4 unique classes with different stats and abilties to take on monsters and level up.

# Design Choices 
I chose my stat formulas to try to make the classes unqiue but aslo balanced

# Bonus Creative Features 
I added two functions. One to give the characters a dodge and block stat. Another to give each class two unique special abilities that temporarily one of their stats. Special abilities are based off of the archetype of the class
